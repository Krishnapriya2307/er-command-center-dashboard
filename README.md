
# ER Command Center Dashboard 

A real-time Emergency Room (ER) dashboard designed to simulate hospital operations and support decision-making in a "War Room" environment.

##  Features

- Live Patient Feed (Triage Levels T1–T5)
- Real-time ER Occupancy tracking
- Average Wait Time calculation
- Critical patient alerts (T1–T2)
- Weather-based alerts (heat, rain impact)
- Auto-refreshing dashboard (every minute)
- Command center style UI

## ⚙️ Tech Stack

- HTML
- CSS
- JavaScript
- Open-Meteo API (Weather Data)

##  Functionality

- Simulates patient arrivals every minute
- Dynamically updates metrics and alerts
- Weather conditions influence hospital load
- Designed for fast decision-making

##  How to Run

1. Download the project
2. Open `index.html`
3. Run using Live Server in VS Code
